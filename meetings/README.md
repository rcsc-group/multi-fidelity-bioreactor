# Weekly meetings

One folder per Thursday meeting: `meetings/YYYY-MM-DD/`. Each folder has

- `README.md`: the figure cards. One card per figure: what it shows, how it was computed (script, data, test), the verdict in one line, the confounds, and the PI feedback after the meeting.
- the figures, numbered in the order of presentation (`01_...png`, `02_...png`), with a `.pdf` next to each when it exists.

The figures are COPIES of the files in `experiments/multifidelity/` taken on the day of the meeting, so a later redraw never changes what was shown.
