# Weekly meetings

This folder is `docs/meetings/` in the repository.

Each Thursday meeting has one folder, named with the date.

Each folder has:
- `README.md`: one card for each figure.
- `TALKING_POINTS.md`: the order of the presentation.
- The figures, numbered in the order of the presentation (`01_...`, `02_...`).

The figures are copies. A new drawing never changes a figure from an old meeting.

Each card has these parts: what the figure shows, how we computed it, the result, the limits.

| Date | Topic |
|---|---|
| 2026-10-15 | numerical diffusion claim, shear and dissipation chain |
| 2026-10-22 | chain and two-level grids, C* extrapolation, repeated flow period |
